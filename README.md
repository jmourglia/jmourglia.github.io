# Portfolio

Base estática lista para hosting gratuito. No requiere Node.

Edita `index.html`: nombre, proyectos, email, links.

## Publicar gratis

1. GitHub Pages:
   `git add . && git commit -m "portfolio" && git push`
   Repo > Settings > Pages > Deploy from branch > main / root.
2. Netlify Drop: arrastra la carpeta a app.netlify.com/drop
3. Cloudflare Pages / Vercel: importa el repo, framework = None, output = `/`.
